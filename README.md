# 花见识 · 三角梅识别首页

这是一个可直接在浏览器打开的单页 UI 原型，按参考图制作了桌面端首页，并补充了移动端布局。

## 交互

- 上传区域支持点击选择、拖拽上传、文件格式和 10MB 大小校验。
- 选择图片后可清除或开始识别；识别过程会展示忙碌和禁用状态。
- 品种卡片可切换识别样例，识别结果卡片和养护建议可打开详情。
- 识别记录保存在当前浏览器会话中。
- 页面底部的“组件交互状态预览”可以选择组件并展示默认、鼠标移入、点击、禁用状态。

当前识别结果使用示例数据模拟交互流程，页面没有连接识别模型或后端服务。

## 打开

直接用现代浏览器打开 `index.html` 即可。
